# 锦少今天带我们吃什么 · 锦少灵签午餐观

> 锦少严选 · 盲盒午餐。摇一摇签筒，让锦少大师替全组决定今天的午饭。

**在线体验：<https://jin-eat.vercel.app/>**（手机打开体验更佳）

一个纯前端的 3D 求签小站。暮色里的小庙，供桌上立着红漆签筒，两侧灯笼摇曳，香炉青烟袅袅。诚心摇签，竹签在筒里哗啦作响，最后飞出一支落在供桌上，再展开一卷签文：第几签、签运、四句签诗、锦少大师解曰、今日宜忌。

场景里的模型、材质、贴图和音效全部由代码实时生成，不使用任何图片、模型或音频文件；站点打包的素材只有一个手写 SVG 图标和 Ma Shan Zheng 毛笔字体（`docs/` 里的截图只给 README 用）。没有后端，也不需要任何密钥或环境变量。

## 玩法

**求签**

- **手机**：双手捧着手机摇。香炉里的三炷香就是诚意值，摇得越起劲烧得越快；香烧完后停手片刻，签就出来了。
- **电脑**：按住空格摇签，松手后静止片刻出签；也可以用鼠标抓住签筒晃一晃。
- **通用**：点一下「摇签 · 立即开炫」自动摇 1.2 秒出签；长按按钮则持续摇签，松手出签。手机上同样可以拖动签筒。

出签后，签筒前倾，竹签探出、弹起，在慢镜头里翻转着落到供桌上，再立起来面向你。钟声响起，签文卷轴展开（手机上从底部升起，向下拖动把手可以收起）。

**签文之后**

- **就它了**：锁定今日午饭，刷新页面也还在。
- **再求一签**：签归筒，重新摇。
- **掷筊问锦少**：圣筊（一平一凸）准了；笑筊再掷，连续三次笑筊锦少就饿了，直接定这家；阴筊则今日排除这家。可以在设置里关掉「掷筊仪式」。
- **一票否决**：每天一次，今日排除这家并重新求签。
- **分享**：生成 1080×1440 的签文图，支持系统分享的设备走分享面板，否则下载 PNG；也可以复制文字。

**名单、签簿与共签**

- **名单**：4–16 家，可以添加、改名、排序、调权重（0–3，0 为不参与），或标记「今日不开」。可一键恢复默认的 9 家。
- **签簿 / 本周战报**：签簿记录最近 14 天的签；首页的本周战报给周一到周五各盖一个章，同一家本周出场 3 次及以上会提示「建议锦少约谈」。
- **避开最近吃过的**（默认开）：昨天吃的、最近 3 天吃过的概率降低，一周没吃的有加成。设置里的「天机可泄露」面板可以看到每家当前的概率。
- **全组共签**：在设置里填同一个口令，名单也一致时，全组每个人当天抽到的签都一样。可以复制带 `#team=口令` 的链接发到群里，打开链接即加入。共签模式下全名单等概率、不看历史，也不能一票否决。

**彩蛋**：周五牌匾变成「周五特供 · 允许奶茶」；2% 概率抽到锦少请客签；同一家连续三天当选会触发「锦少偏爱此店」；下下签有保底文案。

## 体感说明

- **必须 HTTPS**。浏览器只在安全上下文里提供体感数据，用 HTTP 打开时设置里会显示「需要 HTTPS 才能使用体感」。
- 手机首次进入会看到「进殿上香」。iOS 必须由这次点按触发授权弹窗，选「允许」即可；不想用体感可以点「不用体感，直接进」，拖动签筒或按按钮照样能求签。
- 拒绝授权后可以在 设置 → 体感 里点「重新授权体感」；体感开启后，「重新校准」会以当前握持姿势为基准。
- **体感灵敏度**（低 / 中 / 高，默认中，体感开启后出现在 设置 → 体感 里）：只影响签筒、镜头跟随手机动作的幅度和起跳门槛，不影响诚意值的积累和出签快慢。
- 体感数据只在本机使用，不会上传。

## 画质

设置 → 画质 可选 **自动 / 省电 / 标准 / 极致 / 2D**。

| 档位 | 特点                                                                                                  |
| ---- | ----------------------------------------------------------------------------------------------------- |
| 省电 | 不加载物理引擎，竹签抖动由程序模拟；无后期效果，分辨率 1×                                             |
| 标准 | Rapier 物理（懒加载）、泛光与暗角，分辨率最高 1.5×                                                    |
| 极致 | 在标准基础上加清漆材质、阴影、体积光、色差脉冲，粒子更多；桌面端还有景深，分辨率最高 2×（手机 1.75×） |
| 2D   | CSS 3D 签筒，不需要 WebGL；出签、掷筊、分享等玩法完整保留                                             |

**自动**档会根据 CPU 核数、内存、GPU 型号和省流量设置给设备打分，选出初始档位；近年的 iPhone 和旗舰安卓机可以直接进入极致档。运行中有一个帧率守护：只在全速渲染时测帧率（按屏幕刷新率换算目标），持续偏低就逐级降分辨率、再降档，严重掉帧时直接降一整档；持续流畅则逐步回升。档位切换只在空闲时生效，不会打断摇签或出签；来回切换几次后会锁定，避免抖动。

另外：空闲时画面限制在 30 fps（省电档 24 fps），切到后台完全暂停。浏览器不支持 WebGL，或 WebGL 上下文连续丢失两次（或丢失后迟迟无法恢复）时，会自动切换到 2D。

「低晕模式」（跟随系统 / 开 / 关）会缩短、减弱出签动画和镜头运动。

## 部署

项目是纯静态的 Vite 站点，部署在 Vercel。根目录的 `vercel.json` 已配置好：

- 框架 Vite，构建命令 `npm run build`，输出目录 `dist`；
- `/index.html` 和 `/sw.js` 设为 `no-cache`，每次部署立即生效；
- `/assets/*`（带哈希的 JS、CSS、字体分片）缓存一年，标记为 `immutable`。

在 Vercel 导入仓库即可，不需要环境变量。Vercel 默认提供 HTTPS，手机体感可以直接用。

**Service Worker 更新机制**：构建时 Vite 把 `__BUILD_ID__` 注入代码（Vercel 上取提交 SHA 前 8 位加时间戳，本地取时间戳），页面以 `/sw.js?v=<构建号>` 注册 Service Worker，缓存名里带着这个构建号。每次部署都会安装新的 worker，立即接管页面并删除旧缓存。策略是：页面请求网络优先、离线时用缓存；带哈希的静态资源缓存优先；其余同源请求网络优先。Service Worker 只在生产构建和 HTTPS（或 localhost）下注册，首次缓存完成后会提示「已缓存，断网也能求签」。如果新部署后旧的懒加载分片已不存在，页面会自动刷新一次以拿到新版本。当前构建号显示在设置面板底部。

## 隐私

- 名单、签簿、设置都只保存在本机浏览器的 localStorage，没有账号，也没有服务器。
- 除了加载本站自己的静态资源（JS、CSS、字体分片，以及 Service Worker 的缓存），页面不发起任何网络请求；没有统计或追踪脚本，也不请求任何第三方服务。
- 体感数据只在本机使用，不会上传。
- 分享签文时，图片和文字交给系统分享面板或剪贴板，由你自己决定发到哪里。
